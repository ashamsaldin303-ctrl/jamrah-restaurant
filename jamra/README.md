# جَمرة — Jamrah 🔥
موقع مطعم فاخر بتجربة بصرية سينمائية — ملف واحد ذاتي الاحتواء (`index.html`) لا يحتاج أي اتصال بالإنترنت.

## التشغيل
افتح `jamra/index.html` في أي متصفح حديث. كل شيء مضمّن داخله:
الصور (Base64)، الخطوط (Aref Ruqaa + IBM Plex Sans Arabic + Marcellus)، والأنماط والسكربت.

## بنية المشروع
- `index.html` — الحزمة النهائية الذاتية (سلّمها للعميل أو ارفعها كما هي).
- `src/index.html` — قالب HTML المصدر.
- `src/styles.css` — كل الأنماط (توكنات، حركات، تجاوب، دعم prefers-reduced-motion).
- `src/script.js` — كل التفاعلات (فانيلا JS، بلا مكتبات).
- `src/assets/` — الصور المضغوطة.
- `src/fonts/fonts.css` — خطوط مضمّنة Base64.
- `build.py` — يجمع المصدر في `index.html` واحد.
- `compress.py` — ضغط الصور بأبعاد مناسبة لكل استخدام.
- `qa/test.js` — اختبار DOM (jsdom) للتفاعلات الأساسية.

## أبرز المزايا
- شاشة تحميل بستارة ثلاثية ترتفع + رسم شعلة SVG + عدّاد نسبة.
- Hero بجمرات متطايرة على Canvas + Ken Burns + شارة نص دائرية دوّارة + شرائح عائمة.
- سكرول سلس مخصص (lerp) مع إخفاء/إظهار الهيدر حسب الاتجاه، وشريط تقدم علوي.
- مؤشر فأرة مخصص + أزرار مغناطيسية + شرر جمرات عند النقر.
- شريط نص متحرك (Marquee) + ظهور تدريبي مقنّع (line-mask) + Parallax + عدّادات.
- سلايدر أطباق بالسحب والأسهم مع ميلان ثلاثي الأبعاد وشريط تقدم.
- تبويبات قائمة بمؤشر منزلق + Lightbox للمعرض + سلايدر آراء ذاتي مع شريط تقدم.
- نموذج حجز كامل: ملصقات عائمة، أقراص وقت، عدّاد ضيوف، تحقق، ونجاح متحرك.
- RTL كامل، دعم لوحة المفاتيح و prefers-reduced-motion و noscript.

## التخصيص السريع
- الألوان: متغيرات `:root` في `src/styles.css`.
- النصوص/الأقسام: `src/index.html`.
- بعد أي تعديل: `python3 compress.py && python3 build.py` ثم `cd qa && node test.js`.
